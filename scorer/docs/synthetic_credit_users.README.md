# Синтетические данные для кредитного скоринга

Актуальный датасет: [scorer/synthetic_credit_users.csv](scorer/synthetic_credit_users.csv).

В нём 10 000 заявок, 32 входных поля по [интерфейсу scorer](scorer/INTERFACE.md) и `target` — расчётная годовая ставка в процентах. Ставка не означает уже одобренный кредит: в набор включены сценарии возможного отказа.

| Группа | Доля | Диапазон ставок |
| --- | ---: | ---: |
| Низкие | 15% | 7,16–10,85% |
| Обычные | 30% | 12,01–34,97% |
| Высокие | 55% | 35,06–69,99% |

Поля лицензий и кода способа образования удалены из общей схемы; в сокращённом CSV scorer их также нет. Текстовый способ образования сохранён. ИНН представлен только полем `applicant_inn`. Исправлено числовое форматирование регистрационных реквизитов, существующие пропуски сохранены.

Истории заёмщиков взяты из ранее созданной синтетической базы; суммы, сроки, залог и ставки пересчитаны согласованно по сценарным правилам. Новых записей из XML не добавлено. Это авторская симуляция для прототипа, не реальные решения банка.

[Подробное описание: формула, источники, ограничения и проверка](scorer/DATASET.md).

Воспроизведение и проверка (Python 3.10+, без сторонних библиотек):

```bash
python3 scorer/rebuild_dataset.py
python3 scorer/rebuild_dataset.py --check
```

Результаты проверок — в [metadata](scorer/synthetic_credit_users.metadata.json), история изменений по каждой строке — в [аудите](scorer/synthetic_credit_users.audit.jsonl). Аудит содержит сведения, зависимые от целевой переменной, и не должен передаваться модели.
