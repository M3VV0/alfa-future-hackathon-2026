# Синтетические данные для кредитного скоринга

Актуальный датасет: [synthetic_credit_users.csv](../synthetic_credit_users.csv).

В нём 10 000 заявок, 32 входных поля по [интерфейсу scorer](INTERFACE.md) и `target` — расчётная годовая ставка в процентах. Ставка не означает уже одобренный кредит: в набор включены сценарии возможного отказа.

| Группа | Доля | Диапазон ставок |
| --- | ---: | ---: |
| Низкие | 15% | 7,16–10,85% |
| Обычные | 30% | 12,01–34,97% |
| Высокие | 55% | 35,06–69,99% |

Поля лицензий и кода способа образования отсутствуют в общей схеме и сокращённом CSV scorer. Текстовый способ образования сохранён. ИНН представлен только полем `applicant_inn`; регистрационные реквизиты записаны строками без суффикса `.0`.

По историческому описанию истории заёмщиков взяты из ранее созданной синтетической базы; суммы, сроки, залог и ставки пересчитаны согласованно по сценарным правилам, прежние пропуски сохранены, новых записей из XML не добавлено. Без старого CSV и построчного аудита эти сведения о происхождении нельзя независимо проверить. Это авторская симуляция для прототипа, не реальные решения банка.

[Подробное описание: формула, источники, ограничения и проверка](DATASET.md).

Проверка доступного CSV и эксперимент выполняются в [scorer.ipynb](../scorer.ipynb); окружение и порядок запуска описаны в [EXPERIMENT.md](EXPERIMENT.md). Исторические `rebuild_dataset.py`, metadata и построчный аудит отсутствуют в текущей поставке, поэтому повторное создание исходных данных сейчас недоступно. Если аудит будет восстановлен, его сведения, зависимые от целевой переменной, нельзя передавать модели.
