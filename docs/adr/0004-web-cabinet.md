# ADR-0004: веб-кабинет на готовом бэкенде

Дата: 20.10.2026. Статус: принято по запросу пользователя реализовать фронтенд.

Отложенная часть ADR-0003 завершена: DeferredViews удалён, MVC использует Thymeleaf. Реализованы собственная login-страница, заявки с фильтрами и поиском, каталог, новая заявка, редактор, документы, статус/история, компании, профиль, предложения и имитации договора. Окончательный скорер по-прежнему AlwaysRejectScorer; правила скоринга и банковская обработка не изменены.

Bootstrap 5.3.3 и HTMX 2.0.4 поставляются локально в static/assets/vendor. Нет CDN, отдельного frontend-сервиса, Node build step и публичного JSON API. SVG-иконки и CSS-графика созданы в проекте. Скрипты — внешние, CSP не требует unsafe-inline/unsafe-eval; HTMX allowEval/allowScriptTags отключены.

Экранные формы вводят рубли (`amountRubles`, `revenueRubles`, `expensesRubles`, `debtRubles`); LoanForm преобразует их BigDecimal в точные копейки без float. Прежние minor-поля сохраняются на тех же маршрутах для технической коллекции. Это единая web-команда с двумя допустимыми наборами полей, не второй API. Пустые финансовые данные остаются неизвестными, а не нулями. Ошибки возвращают 422 и исходный ввод; исправленная форма получает новый command_id. У каждой формы отдельный UUID — загрузка документа не расходует ключ сохранения/отправки заявки.

Status polling выполняется HTMX каждые 3 секунды и прекращается после завершения/NEEDS_INFO/FAILED. Техническая задержка отличается от отказа. Status-фрагмент включает историю и действие клиента; редактор и выбор документов им не заменяются. JS не хранит бизнес-состояние, только отмечает несохранённый ввод и предотвращает отправку старой сохранённой версии при наличии правок. Сессия/CSRF/membership/version и идемпотентность остаются на сервере.

Для работы с демонстрационными документами GET `/app/applications/{id}/report-template` отдаёт attachment JSON по уже сохранённым финансовым данным, после проверки прав. Поля должны быть заполнены; при их отсутствии 422. POST `/app/documents` может вернуть HTMX-панель документов вместо навигации, сохраняя несохранённые поля соседнего редактора. Документы прикрепляются только после явного сохранения заявки.

`loan` — имя MVC-модели заявки: `application` зарезервировано web-контекстом Thymeleaf. Доменный сервис и внутренние API не переименованы. HTML выводит пользовательские данные через th:text/th:field с экранированием. Model version обновляется при переходе по успешному redirect; устаревшая вкладка получает 409 с действием обновления.
