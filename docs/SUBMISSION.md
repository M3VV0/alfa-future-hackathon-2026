# Комплект сдачи MVP

## Что передаётся

- Исходники Java и Python, обученный артефакт и manifest его версии/диагностической проверки.
- Compose и Dockerfile, зафиксированные версии образов и lock-файл Python.
- README с одной командой запуска, конфигурацией, тестовыми аккаунтами и проверкой основного пути.
- Архитектура, состояния и модель данных: `docs/architecture/mvp.md`.
- API: `code/app/backend/src/main/resources/openapi/credit.yaml`, `docs/openapi/scorer.yaml`;
  описание обмена: `docs/SCORER.md`; Postman: `docs/requests/credit-mvp.postman_collection.json`.
- Синтетические профили/аккаунты, JSON-отчёты в `demo/reports`, тестовые сценарии и `scripts/verify_mvp.py`.
- `THIRD_PARTY_NOTICES`, описание ограничений и сценарного исследования `docs/research.md`.

Отчёт выполненных проверок: `docs/VERIFICATION.md`.

## Версия

Проверяемый идентификатор — итоговый commit ветки `scorer-service`:

```sh
git rev-parse HEAD
```

Зафиксируйте этот hash в форме сдачи после завершения проверок. Не подменяйте версию коммитами
после дедлайна. При подготовке архива включите артефакт `selected_model.joblib`, lock-файлы и
документацию; не включайте `.env` с личными секретами, venv, `target` и локальные данные PostgreSQL.

## Действия вне локальной реализации

Репозиторий должен быть доступен жюри. Для приватного репозитория владелец предоставляет доступ
`alfa-hack-2026`. Наличие доступа нельзя подтвердить локальной сборкой. Отправка ветки на GitHub,
указание hash в форме сдачи и предоставление доступа должны быть проверены владельцем перед сдачей.
Бесплатный внешний стенд желателен, но локальный запуск полностью автономен и обязателен.

## Честные ограничения

Только синтетические данные; ставка — прогноз модели на синтетической задаче, не вероятность
дефолта. Реальных реестров, БКИ и ФНС нет: поля компании заявлены, а не проверены такими системами.
Документы — JSON определённого формата. Подпись и выдача — явно помеченные имитации. Локального
генератора скоринговых ответов и резервного Java-скорера нет; используется поставляемый CatBoost.
Интервью с реальными МСП не проводились, продуктовые гипотезы не выдаются за результаты CustDev.
